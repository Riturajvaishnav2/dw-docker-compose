================================================================================
FORECAST PIPELINE - QUICK START
================================================================================

THREE COMMANDS TO RUN THE ENTIRE PIPELINE:

1. START INFRASTRUCTURE:
   $ ./start.sh

2. RUN PIPELINE (upload CSV + trigger DAG + verify files):
   $ ./start_forecast_pipeline.sh

3. MONITOR LOGS (in another terminal):
   $ ./watch_containers.sh airflow

================================================================================
WHAT HAPPENS:

Step 1 (./start.sh):
  ✓ Starts Iceberg REST, Trino, Airflow, Spark, S3 containers
  ✓ Generates Trino catalogs
  ✓ Waits for all services to be healthy

Step 2 (./start_forecast_pipeline.sh):
  ✓ Verifies CSV file exists (warehouse_forecast_1000_rows.csv)
  ✓ Uploads CSV to S3: s3://landing_test/tenant/EE/Bronze/Forecast/
  ✓ Triggers forecast_ingestion DAG
  ✓ Monitors execution (100+ seconds)
  ✓ Verifies file movement:
    - original/2026-07-03/ (backup before validation)
    - processed/2026-07-03/ (backup after success)

Step 3 (./watch_containers.sh):
  ✓ Shows live logs from containers
  ✓ Watch validation, loading, and errors in real-time

================================================================================
TROUBLESHOOTING:

If pipeline fails:
  1. Check logs: ./watch_containers.sh airflow
  2. Check S3 upload: s3://landing_test/tenant/EE/Bronze/Forecast/
  3. Check DAG: http://localhost:8080/dags/forecast_ingestion
  4. Check error messages for schema/validation issues

If containers won't start:
  1. Restart: docker compose down && ./start.sh
  2. Clean restart: docker compose down -v && ./start.sh
  3. Check resources: docker stats

If file movement fails:
  1. Verify S3 credentials in .env
  2. Check bucket exists: landing_test
  3. Verify path: tenant/EE/Bronze/Forecast/
